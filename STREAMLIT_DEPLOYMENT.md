# Streamlit Deployment Status

This project is now OpenWebUI-only for production and local testing.

## Important

- Streamlit Community Cloud is not used as the primary application host.
- The supported interface is OpenWebUI backed by `openwebui_api.py`.
- For deployment guidance, use `OPENWEBUI_DEPLOYMENT.md`.

## If you still need Streamlit

Use Streamlit only as a simple launcher page that links to your hosted OpenWebUI URL.
Do not use Streamlit as the main chat interface for this repository.
